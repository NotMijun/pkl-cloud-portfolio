Pengertian Cloud Computing
Cloud Computing adalah cara menggunakan sumber daya komputasi, seperti server, penyimpanan, dan jaringan, melalui layanan yang dapat diakses sesuai kebutuhan. Kita tidak harus membeli dan mengelola seluruh perangkat fisiknya sendiri.

Menurut NIST SP 800-145, Cloud Computing memiliki lima karakteristik utama.
1. On-Demand Self-Service (Layanan Mandiri)
- Artinya: Pengguna bisa menyiapkan dan menggunakan layanan cloud sendiri saat dibutuhkan, tanpa harus meminta bantuan langsung dari petugas penyedia.
- Contoh nyata: Tim IT membuat virtual server baru melalui dashboard AWS ketika ingin menjalankan aplikasi.
2. Broad Network Access (Akses Melalui Jaringan)
- Artinya: Layanan cloud dapat diakses melalui jaringan dengan berbagai perangkat, seperti laptop dan HP.
- Contoh nyata: Mahasiswa mengunggah tugas ke Google Drive dari laptop, lalu membuka file yang sama melalui HP.
3. Resource Pooling (Berbagi Sumber Daya)
- Artinya: Penyedia cloud menggabungkan sumber daya seperti server dan penyimpanan untuk melayani banyak pelanggan. Sumber daya dialokasikan sesuai kebutuhan, dan lingkungan pelanggan dipisahkan.
- Contoh nyata: Dua perusahaan menggunakan layanan AWS yang berjalan di infrastruktur penyedia yang sama, tetapi masing-masing mempunyai akun dan data yang terpisah.
4. Rapid Elasticity (Kapasitas Cepat Menyesuaikan)
- Artinya: Kapasitas layanan cloud bisa ditambah atau dikurangi dengan cepat sesuai kebutuhan, termasuk secara otomatis.
- Contoh nyata: Saat promo 11.11, toko online menambah kapasitas komputasi untuk menghadapi lonjakan pengunjung, lalu menguranginya setelah promo selesai.
5. Measured Service (Penggunaan Terukur)
- Artinya: Penggunaan sumber daya cloud, misalnya penyimpanan atau komputasi, diukur dan bisa dipantau oleh pengguna serta penyedia.
- Contoh nyata: Perusahaan memantau jumlah GB penyimpanan yang dipakai melalui dashboard cloud untuk mengetahui penggunaan dan perkiraan biayanya.
