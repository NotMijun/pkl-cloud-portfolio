Target PKL
1. Memahami dasar Cloud Computing dan lima karakteristik cloud menurut NIST.
2. Memahami perbedaan cloud dan server on-premise.
3. Mempelajari layanan cloud seperti komputasi, penyimpanan, dan jaringan.
4. Memahami konsep biaya CapEx dan OpEx dalam penggunaan cloud.
5. Melakukan latihan sederhana menggunakan layanan cloud dan mendokumentasikan hasilnya di GitHub.
